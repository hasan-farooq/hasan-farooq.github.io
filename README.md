# Hasan Farooq — Research Portfolio

Static academic portfolio for https://hasan-farooq.github.io/.

## Publish

Create the public repository `hasan-farooq/hasan-farooq.github.io` and upload these files at its root. In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/ (root)**.

## Local preview

Run `python3 -m http.server 8000` from this folder and open http://localhost:8000.

## Editing

- `index.html`: content and links
- `styles.css`: appearance and light/dark themes
- `intro.js`: interactive experiments and controls
- `assets/`: publication figures
